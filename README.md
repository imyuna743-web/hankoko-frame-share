# 한코코 프레임 공유소

로그인 없이 프레임을 공유하고 한코코 로그 백업기로 불러오는 갤러리입니다.

## 주요 기능

- 추천순·최신순·좋아요순 정렬
- 브라우저에 저장되는 북마크
- 1:1 크롭 및 최소 512×512 업로드 검사
- 원형·둥근 사각형·사각형 필수 태그와 사용자 태그
- IP를 비공개 해시로 변환한 익명 4자리 식별번호
- IP 기준 좋아요·신고 중복 제한
- 신고 10회 누적 시 자동 비공개 및 이미지 삭제
- OpenAI Moderation API를 이용한 업로드 전 이미지 검사

## 익명 식별 방식

원본 IP는 데이터베이스에 저장하거나 화면에 공개하지 않습니다. 서버 비밀키로 IP를 HMAC 해시한 뒤 닉네임 뒤에 안정적인 4자리 식별번호만 표시합니다. 공용 네트워크나 통신사 NAT에서는 여러 이용자가 같은 식별번호를 사용할 수 있고, 네트워크나 VPN이 바뀌면 번호도 달라질 수 있습니다.
